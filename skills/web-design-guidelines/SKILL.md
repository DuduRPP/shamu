# Review web interface code

Use the [bundled Vercel guidelines](references/command.md) as the rule set. Inspect the files or diff the user specified and follow the rule set's finding format. Point each finding to its source location and state which interaction could fail. If a rule requires a runtime check, distinguish the checks you performed from those still pending.

The bundled source is the [pinned Vercel Labs guidelines](https://github.com/vercel-labs/web-interface-guidelines/blob/434b7f91364665f2f733b310ec54809bf8f37937/command.md), distributed under the [Vercel Labs license](LICENSE).
